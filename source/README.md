- 出典: 農研機構農業環境研究部門「歴史的農業環境閲覧システム」 https://habs.rad.naro.go.jp/
- ライセンス: [CC BY 2.1 JP](https://creativecommons.org/licenses/by/2.1/jp/)（出典「農研機構農業環境研究部門」を明示すれば申請不要・無償で利用可）
- 原図: 国土地理院所蔵の迅速測図（HABS は国土地理院の承認 平19総測、第10号 を得て複製）
- 作成方法: HABS のタイル `https://habs.rad.naro.go.jp/rapid16/{z}/{x}/{y}.png`（TMS 形式, y 反転）を z=16 で 8×8 枚取得し 2048×2048px に結合
